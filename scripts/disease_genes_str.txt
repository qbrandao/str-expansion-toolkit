# Genes carrying a tandem repeat whose expansion is associated with disease.
#
# A starting point for extract_loci_report.py, NOT a curated clinical panel.
# Review it against a current source and against the referring clinician's
# question before reporting anything from it. Names follow HGNC; the script
# matches them case insensitively, since annotation files disagree on the case
# of names such as C9orf72.
#
# Only gene names are listed here on purpose. Repeat coordinates and
# pathogenic thresholds are not: they differ between reference builds and
# between sources, and getting one wrong by a few base pairs silently points
# the report at the wrong repeat. The coordinates come from the genes BED
# passed on the command line, and the thresholds are the clinician's call.
#
# Usage:
#   ./scripts/extract_loci_report.py --merged-vcf <sample>.merged.vcf \
#       --genes-bed genes.bed.gz --genes-file scripts/disease_genes_str.txt \
#       -o <sample>_report.tsv
